# 官网图片放这里

来源：https://www.xiaomiev.com/skynomad/n90
（云端构建环境无法访问 xiaomiev.com，所以需要手动上传。）

1. 用 Chrome 打开上面的网页，一直滚动到页面底部，让所有图片都加载出来。
2. 按 Ctrl+S（Mac：Cmd+S），保存类型选“网页，全部”，会得到一个“…_files”文件夹，官网图片都在里面。
3. 在 GitHub 打开本文件夹 → Add file → Upload files，把体积较大（一般 >150 KB）的图片拖进来，
   提交到 claude/youthful-albattani-tc2nsl 分支即可。jpg / png / webp / avif 都可以，文件名不用改。
