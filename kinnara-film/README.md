# 《渡》紧那罗 × 阿羞 · 故事短片（旁白版）

改编自电视剧《西游记后传》（2000）里紧那罗与阿羞的往事。前半段是旁白，配原创配乐；阿羞死去、灯灭之后，《大天蓬》副歌（27.7 秒，恩几翻唱）原样进来；歌后三句旁白收尾。
画法是工笔重彩，画在绢本上，配色取自敦煌；只在关键处用壁画开裂、剥落的效果。
画面、配乐、音效都由代码生成；旁白由 Gemini TTS 配音（AI 配音，提示词见 `vo/AISTUDIO_PROMPT.md`）。

交付两版，各 130.8 秒：16:9（1920×1080）和 9:16（1080×1920）。第 0 帧是封面。
歌曲、配音录音和成片都**不入库**（版权），仓库里只有源码。

## 故事
紧那罗是世尊座下的大护法，奉命南下西牛贺洲传法。大祭司出了三道难题：让小偷阿溜不再偷，恶霸阿刀不再打，妓女阿羞不再倚门卖笑。
他为阿羞点了一盏灯，她第一次觉得灵魂在战栗，于是洗尽铅华，在灯前立誓：此生此身，再不让别的男人碰触。
大祭司出尔反尔，把他打入死牢。那一夜，阿羞提着那盏灯走进大祭司的门，破了誓，换他一条生路。他获救那天，她选择了死。
他抱着她去见佛祖优婆罗陀，换来四个字：六根不净。怨念化作魔罗，白衣成了黑袍。从此世上再无紧那罗，只有无天。

片名「渡」：他奉命来渡她，她舍身渡了他，佛却不渡他们。
贯穿全片的是一盏灯：他为她点亮，她提着它去救他，她死时灯灭，最后无天守着那盏熄灭的灯。
舍身和自尽都只作暗示：用门合上、红花坠落、灯灭来表现，不出现过程。

## 源码
- `src/vo_prep.py`：把一条 Gemini 配音切成 15 句。先按能量找出有声段，再用 SenseVoice（sherpa-onnx）拿到每个字的时间，和台词对齐（difflib，允许同音字），在两句之间最安静处下刀。输出 `build/vo/lines/Lxx.wav` 和每个字在句内的时间。
- `src/timeline.py`：把 15 句和歌曲排上时间线（句间停顿手工设定，就是全片的节奏），输出 `build/vo/manifest.json`。画面和声音都按这份时间表、精确到每个字对齐。
- `src/tex.py`：纹理（Python 预生成）：墙面、灰泥、剥落图、颗粒、斑驳，以及绢本（经纬织纹、粗细不匀的丝、霉斑）。
- `src/kit.js` / `src/mural.js`：绘画工具：矿物颜料填色（边缘积色、疏密不匀、颗粒、剥落）、铁线描、晕染、贴金、朵云、火焰纹、头光与法轮、散花、会跑的裂纹、成片剥落的颜料、光束与尘埃、灯光。
- `src/heroine.js`：阿羞。四分之三侧面的半身像，脸由样条曲线的关键点控制：
  - 衣服：石榴红长裙加金披帛和璎珞，或素白交领；
  - 发型：高髻、金步摇和花，或长发披散加一朵红花；
  - 表情：冷、含泪、月牙眼的笑、闭目；
  - 头可以绕颈部转动。
- `src/figures.js`：
  - 紧那罗侧像，头可抬低；墨从衣角往上爬，白衣化为黑袍（无天，红眼）；
  - 大祭司；阿溜、阿刀；世尊；
  - 远景小人物：下山的行僧、抱着她上灵山、跪在座前；
  - 提灯的背影、钉门。
- `src/lib.js`：闪电、法轮、黑红火焰背光、散花、灵山长阶、片名「渡」、朱印等。
- `src/scenes.js`：全部镜头、字幕、榜题歌词、封面和片尾。
- `src/audio.py`：声音（见下）。
- `src/engine.js` / `src/render.js` / `src/reel.html`：逐帧渲染。无头 Chromium 画每一帧，CPU 合成运动模糊、泛光、色散、暗角、胶片颗粒，原始像素直接送进 ffmpeg。

## 声音
`src/audio.py`：
- 旁白按时间表放置，每句音量向 −16.5 LUFS 靠拢一部分（轻声的句子仍然略轻）。
- 配乐取歌曲的调（B 大调 / 升 G 小调五声），全部原创、由代码合成：
  - 无天：低音持续音；
  - 阿羞：温暖的长音和古琴；
  - 死牢和那扇门：一路加快的心跳；
  - 灯灭之后静一拍，进歌。
- 音效：油灯点燃、锡杖与脚步、颂钵、水洗、落金、锁链、门轴与关门、红花坠地、雷、开裂与剥落、法轮、头光碎裂、暗火、「六根不净」四声重印、魔罗升起、睁眼时的暗钟。
- 旁白一出现，配乐自动压低约 14 dB，音效压低约 6 dB。
- 歌曲放在 78.37 秒，不剪不改，只调音量；歌尾接一段混响尾音。
- 整体 −14 LUFS，真峰值 −1 dBTP。

## 生成
```
# 1. 旁白：把 vo/AISTUDIO_PROMPT.md 里的代码块粘进 Google AI Studio（Gemini TTS），生成的 wav 放到 build/vo/take.wav
#    SenseVoice 模型（sherpa-onnx 的 GitHub releases：sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17）解到 assets/models/，或设 SENSEVOICE_DIR
python3 src/vo_prep.py      # → build/vo/lines/
python3 src/timeline.py     # → build/vo/manifest.json
# 2. 歌曲（不入库）
cp <歌曲>.wav music/song.wav
# 3. 字体（不入库）：npm pack @fontsource/ma-shan-zheng @fontsource/zhi-mang-xing @fontsource/liu-jian-mao-cao @fontsource/noto-serif-sc，解到 assets/fontsrc/<名字>/
python3 src/tex.py          # 纹理 → build/tex/
python3 src/audio.py        # 声音 → build/audio.wav
REEL_NAME=du_film PLAYWRIGHT=/opt/node22/lib/node_modules/playwright node src/render.js --workers 4 --aspect h   # 16:9 → out/du_film_h_master.mp4
REEL_NAME=du_film PLAYWRIGHT=/opt/node22/lib/node_modules/playwright node src/render.js --workers 4 --aspect v   # 9:16
node src/render.js --stills 31.5,79.6 [--aspect v]              # 单帧检查 → build/stills/
node src/render.js --stills 0 --lab ax_white_smile:face         # 单独看人物：ax_red_cool / ax_red_tear / ax_white_closed / ax_white_smile / ax_white_tear（:face 看脸），kin:<0–1 墨>，lamp
```
