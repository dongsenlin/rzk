# 《渡》紧那罗 × 阿羞 · 大天蓬 MV（敦煌壁画手绘版）

故事改编自电视剧《西游记后传》（2000）第 14 集紧那罗与阿羞的往事；音乐沿用《大天蓬》副歌 27.7 秒片段（恩几翻唱）。
歌曲与成片**不入库**（版权），这里只有源码。
交付：16:9（1920×1080）和 9:16（1080×1920）两版，各 36.2 秒 = 第 0 帧封面 + 6 秒故事片头 + 27.7 秒歌曲 + 2.5 秒片尾。

## 故事
世尊座下大护法紧那罗南下传法，大祭司出三道难题：渡化小偷阿溜、恶霸阿刀、妓女阿羞。阿羞被打动，发誓从良，也爱上了他。
大祭司翻脸，要烧死紧那罗；阿羞去求大祭司救他，破了誓言后自尽。紧那罗抱着她上灵山求世尊，却被斥为佛门败类、逐出佛门，
一念成魔，成了无天。片名「渡」：他奉命来渡她，她舍身渡了他，佛却不渡他们。

## 画面：一面古壁画活了过来（全部由代码绘制）
- `src/tex.py`：墙面纹理（Python 预生成）：白粉地、泥层、水渍与潮线、灯烟、砂粒、稻草、龟裂纹、颜料剥落图、矿物颗粒。
- `src/kit.js`：路径解析、笔触、晕染等基础工具（与上一版 MV 共用）。
- `src/mural.js`：矿物颜料填色（边缘积色、疏密不匀、颗粒、剥落）、铁线描、晕染、沥粉贴金、朵云、火焰纹、头光与转轮、散花；
  壁画「活过来」的方式：会跑的裂纹、成片剥落的颜料（露出土红底稿）、从裂缝向外蔓延的颜料氧化变黑（变色）、光束与尘埃、油灯光。
- `src/figures.js`：人物。阿羞（唐代仕女：高髻、花钿、红裙、石绿披帛、璎珞）；紧那罗（僧人侧像，头可抬起）及其氧化变黑的无天；
  大祭司；世尊（正面坐佛，莲座）；远景小人物：抱着阿羞上灵山、跪在世尊座前、月下无天的背影。
- `src/scenes.js`：时间线与场景。歌词写在壁画的「榜题」里，随演唱逐字写出（马善政楷书），片名「渡」用志莽行书。

## 声音
`src/audio.py`：歌曲原样放在 6 秒处。片头：洞窟的空气声和滴水、油灯点燃、低音持续音、灯光找到二人时各一声颂钵、写字、落印大鼓、铜钟与古琴、渐强入歌。
歌中只叠很轻的点缀：「天」「怒」雷声，「地也恼」墙裂与落灰，「再无」颜料剥落，「轮回」转轮，「魄」头光碎裂，「飞」暗火。整体 −14 LUFS，真峰值 −1 dBTP。

## 生成
```
cp <歌曲>.wav music/song.wav
# 字体（不入库）：npm pack @fontsource/ma-shan-zheng @fontsource/zhi-mang-xing @fontsource/noto-serif-sc，解到 assets/fontsrc/<名字>/
python3 src/tex.py        # 墙面纹理 → build/tex/
python3 src/audio.py      # 声音 → build/audio.wav
REEL_NAME=du_mv PLAYWRIGHT=/opt/node22/lib/node_modules/playwright node src/render.js --workers 4 --aspect h   # 16:9
REEL_NAME=du_mv PLAYWRIGHT=/opt/node22/lib/node_modules/playwright node src/render.js --workers 4 --aspect v   # 9:16
node src/render.js --stills 0 --lab axiu|axiuface|kin|kinup|kindark|buddha|priest|carry|kneel|wutian   # 单独看人物画稿
```
