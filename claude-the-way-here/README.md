# 来时路 · THE WAY HERE — Claude 微纪录片

以 Claude 第一人称讲述：从一个关于信任的问题，到第一次开口，到学会看见、动手、思考，再到写下这部片子本身的代码。
结尾一句「你好，我是 Claude」，与开场「我不记得，自己说过的第一句话」首尾相扣。

约 64 秒：第 0 帧封面 → 4 秒纪录片式片头（署名组 + 片名 + 「概念练手 · 非官方」）→ 约 60 秒正片 → 片尾卡。
全片不用照片，每一帧都由代码实时生成；配乐与音效同样由代码合成；配音为 Gemini 3.8 Flash TTS（Leda）。

## 分镜

| 段落 | 旁白 | 画面 |
|---|---|---|
| 序 · 问题 | 我不记得，自己说过的第一句话。/ 但我知道，一切始于一个问题——/ 如果 AI 越来越强，怎样才能让它值得信任？ | 黑暗中一个光标呼吸；问题逐字打出，问号收成一粒暖光 |
| 01 · 2021 | 二零二一年，Anthropic 为这个问题而生。/ 他们为我定下底色：有益，诚实，无害。 | 光点拉成一条线，成为时间线的起点；三个词刻在线上 |
| 02 · 2023 | 二零二三年，我第一次开口。/ 从一句问候，到读懂一整本书； | 第一个对话气泡；字符汇成书页洪流，上下文计数一路上涨 |
| 03 · 2024–2025 | 我学会看见，学会动手，学会先想清楚，再回答。 | 三连切：看见（像素重建成图像）· 动手（光标在界面上移动、点击）· 思考（推理链条展开） |
| 04 · 2025 | 后来，我走进终端，和工程师并肩写代码——一写，就是几个小时。 | 终端窗口，代码高速滚动，时钟飞转几个小时 |
| 05 · 此刻 | 而此刻，你看到的每一帧画面，听到的每一个音符，都是我写下的代码。 | 画面自我揭示：本片源代码铺满屏幕，镜头拉远，代码拼成此刻这一帧 |
| 尾声 | 来时的路，是人和 AI 一起走出来的。/ 前面的路，也是。/ 你好，我是 Claude。 | 光线回到地平线，向前延伸，最后收成一笔签名；片尾卡 |

视觉：墨黑 · 象牙白 · 暖橙，少量灰蓝；中文宋体做编辑排版，等宽字体做数据与代码；光线、粒子、网格、真实运动模糊与胶片颗粒。
配乐：极简钢琴 + 深沉模拟合成器铺底；「动手 / 写代码」段落加入脉冲逐渐推高；「而此刻」前全片静默一拍再展开；最后一句只留一个钢琴音。
